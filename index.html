Aeries to SkillsUSA roster converter

Turn an Aeries class roster into a SkillsUSA upload file. Work through each step in order; the next step unlocks when the current one is done.

  1. Step 1

    Upload the SkillsUSA template

    Download the roster template (.xlsx) from the SkillsUSA registration site, then upload it here. The training programs it lists will appear in Step 2.

    Look for a file named SkillsUSA_TemplateSimple.xlsx, usually in your Downloads folder.

    No file chosen

    Getting the SkillsUSA template

    IMPORTANT: You must have training programs in order to upload data. Check that you do by clicking on the "Membership" icon on the home page, and checking that you have Training Programs listed. Watch this video (until about the 3 minute mark) for help adding training programs.

    Select "Upload Membership Data" from the "Membership" tab.

    Download the "Simple Template".

  2. Step 2

    Choose a training program

    Pick the training program these students should be added to.

  3. Step 3

    Upload your Aeries roster

    Export the Class Roster report (.xlsx) from Aeries and upload it here. It can include several classes; students in more than one class are added only once.

    Look for a file whose name starts with PrintClassRosters_ followed by numbers, usually in your Downloads folder.

    Exporting your roster from Aeries

    On the left sidebar, select "Reports", then "Attendance", and select the "Class Rosters" option.

    Select (1) the XLSX, (2) check the box to add fields to the printout, (3) Add the GN and SEM fields to print.

    Select the classes in your CTE programs to be included in the print.

  4. Step 4

    Download the upload file

    Download the finished Excel file, then upload it on the SkillsUSA registration site. To make another file, choose a different roster in Step 3 or a different program in Step 2.

Files are read in your browser and never leave this computer.
